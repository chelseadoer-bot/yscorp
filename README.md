# 발주양식 통합 서비스

여러 업체가 보내오는 **제각기 다른 발주 엑셀 양식**을 하나의 **표준 발주 양식(최종 통합본)**
으로 자동 변환한다. 파일을 넣으면 `날짜_업체명_발주 수정본.xlsx` 로 바로 받을 수 있다.

두 가지 방법으로 쓸 수 있다.

- 🌐 **웹(사이트)** — 브라우저에서 엑셀을 끌어다 놓으면 변환본을 바로 내려받는다. (`web/`)
  모든 처리가 브라우저 안에서만 일어나 **고객 정보가 서버로 전송되지 않는다.**
- 🐍 **CLI(파이썬)** — 여러 파일을 한 번에 일괄 변환하거나 자동화에 쓴다. (`convert_po.py`)

---

## 0. 웹 서비스 (사이트)

```
web/
  index.html            # 사이트 화면
  styles.css            # 스타일 (라이트/다크 테마)
  app.js                # 변환 엔진 + UI (파이썬 로직과 동일)
  vendor/exceljs.min.js # 엑셀 입출력 라이브러리(로컬 포함, 외부 CDN 불필요)
  build.js              # 위 파일들을 단일 HTML(dist/artifact.html)로 묶는 빌드
```

**바로 쓰기 (설치 불필요)**
- 로컬: `web/index.html` 을 브라우저로 열면 끝. (인터넷 없이도 동작)
- 팀 공유: 저장소를 GitHub Pages로 켜면 `.../web/` 주소로 접속해 함께 사용.

**단일 파일로 배포**
```bash
node web/build.js      # dist/artifact.html 하나로 묶음 (이메일·호스팅에 편리)
```

동작: 엑셀을 올리면 → 업체 양식 자동 인식 → 미리보기 → `업체명/날짜` 확인·수정 →
`날짜_업체명_발주 수정본.xlsx` 다운로드. 여러 파일은 **전체 다운로드**로 한 번에 받는다.

## 1. CLI 사용법

```bash
# 원본 파일 여러 개를 한 번에 변환 (출력 폴더 지정)
python convert_po.py 유니어원본.xlsx 칡즙원본.xlsx -o outputs

# 날짜/업체명을 직접 지정 (자동 감지가 안 되거나 덮어쓰고 싶을 때)
python convert_po.py 원본.xlsx --vendor 블루베리퓨레 --date 260730 -o outputs
```

- `--date` : 파일명에 쓸 날짜 `YYMMDD`. 미지정 시 **원본에서 추출**(주문일자 등)하거나 **오늘 날짜** 사용.
- `--vendor` : 업체명 강제 지정. 미지정 시 **자동 감지**.
- 출력 파일명 규칙 : **`날짜_업체명_발주 수정본.xlsx`**

설치:

```bash
pip install -r requirements.txt   # openpyxl
```

## 2. 표준 출력 양식 (기준 0730/260730 통합본, 12열)

| NO | 주문인명 | 수령인명 | 수령인핸드폰번호 | 수령인핸드폰번호 | 우편번호 | 주소 | 배송메세지 | 상품정보 | 주문수량 | 택배사 | 송장번호 |
|----|---------|---------|----------------|----------------|---------|------|-----------|---------|---------|-------|---------|

- 글꼴 **맑은 고딕 10pt**, 전 셀 얇은 테두리, 택배사·송장번호 헤더 연한 주황
- **주문인명은 채워서** 출력 — 주문인 정보가 따로 없으면 수령인명으로 채운다(앞 열이 비지 않도록)
- **수령인핸드폰번호 두 열** 모두 수령인 전화번호(기준 파일과 동일)
- 우편번호는 **`XXX-XX` 5자리**(예: `036-32`), 앞자리 0 보존, 전화·우편·송장은 텍스트 서식

### 여러 파일을 하나로 (통합/merge)
- 웹: 여러 파일을 올린 뒤 **「통합본 1개로 받기」** → `날짜_통합_발주 수정본.xlsx` 하나로 (NO 연속)
- CLI: `python convert_po.py a.xlsx b.xlsx c.xlsx --merge -o outputs`

## 3. 현재 지원하는 업체 양식

| 업체(key) | 자동감지 기준 헤더 | 업체명 확정 | 비고 |
|-----------|-------------------|:----------:|------|
| 유니어 (`unier`) | 수신인 · 상품명 · 실수량 | ✅ (식별번호 열) | 주소 끝 이름·전화 제거, 우편 앞자리 0 복원 |
| 패션지오 (`fashiongeo`) | 품목명 · 수취인 명 · 배송지 | ✅ (시트명) | 배송지 앞 `[우편번호]` 분리, 주문일자→날짜 |
| 다온에프앤씨 (`daon`) | 주문인 · 받는인 · 상품명 | ✅ (파일명) | 주문인/받는인·연락처, 전언→배송메세지 |
| 칡즙 (`chikjeup`) | 수령인 · 주문상품명 · 비고 | ⚠️ 추정(확인 필요) | 상품명 끝 `/N개` → 주문수량 분리 |
| 블루베리퓨레 (`blueberry`) | 수령인명 · 수령인연락처 · 배송시 요청사항 | ⚠️ 추정(확인 필요) | 상품명 끝 `▶ 기본/N개` → 주문수량 분리 |

> ⚠️ **칡즙 / 블루베리퓨레**는 원본에 업체명이 없어 임시 이름을 붙였다.
> 웹에서는 화면에서 바로 수정, CLI는 `--vendor` 옵션 또는 `vendors.py` 의 `default_name` 수정.

### 데이터 정리 규칙
- 전화번호 : `~` → `-`, 공백 제거
- 우편번호 : 하이픈 없는 5자리, 4자리는 앞 `0` 복원, `[509-51]` 형태는 주소에서 분리
- 주소 : `~` → `-`, 끝에 중복으로 붙은 `이름 전화번호` 제거
- 주문수량 : 상품명 끝 `/N개`·`▶ 기본/1개`는 **주문수량**으로 분리(별도 수량 열이 있으면 그 값 사용)
- 날짜 : 원본 주문일자 → 파일명 날짜 순으로 자동 추출(없으면 오늘)

## 4. 새 업체 추가 방법

`po_converter/vendors.py` 의 `VENDORS` 리스트에 `Vendor` 하나만 추가하면 된다.

```python
Vendor(
    key="새업체",
    default_name="새업체명",
    signature=["그업체헤더1", "그업체헤더2"],   # 이 헤더들이 모두 있으면 이 양식으로 인식
    map_row=_map_새업체,                       # 한 행(Row) → 표준 필드 dict 로 변환
)
```

`_map_새업체(row)` 안에서 `row.h("헤더이름")`(여러 후보 헤더 가능) 또는 `row.pos(3)`(열 위치)로 값을 읽어
표준 필드(`orderer, recipient, phone, postcode, address, message, product, qty, courier, invoice`)로 채운다.
(웹 서비스에 반영하려면 `web/app.js` 의 같은 매핑도 함께 수정)

## 5. 구조

```
convert_po.py            # CLI 진입점
po_converter/
  format_spec.py         # 표준 양식 정의 + 서식(맑은 고딕/테두리/열너비) 기록
  cleaning.py            # 전화·우편·수량·주소 정리 유틸
  vendors.py             # 업체별 자동감지 + 매핑 (여기에 업체 추가)
  converter.py           # 원본 로드 → 업체 감지 → 표준 행 생성 → 저장
tests/test_convert.py    # 합성 데이터 검증 (개인정보 미포함)
```
